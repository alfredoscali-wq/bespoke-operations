# Bespoke Operations

Bespoke Operations es una plataforma para la gestión integral de empresas de servicios técnicos, operaciones en campo y atención al cliente.

El objetivo del sistema es coordinar el trabajo diario de todos los sectores de la empresa mediante procesos conectados, motores reutilizables y una arquitectura modular.

El producto se encuentra organizado alrededor de procesos de negocio y no de simples registros de información.

La documentación oficial del producto se encuentra en el archivo:

docs/HANDBOOK.md

Todo desarrollo nuevo deberá respetar la arquitectura allí definida.
